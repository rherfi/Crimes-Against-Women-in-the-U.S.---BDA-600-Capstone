## Descriptive vs model-based
- Descriptive findings summarize observed values (rates, shares, rankings).
- Associations can be described when a model relates variables, but **association is not causation**.
- Model-based estimates should specify the model type, covariates, and uncertainty.

## Example caveat (what the bot should say)
If the user asks “Did VAWA cause X?” the bot should explain that V1 can show trends and associations, but causal claims require an identification strategy.
