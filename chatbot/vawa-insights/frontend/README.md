# VAWA Insights Bot (Frontend) — React

This is the **V1 prototype** chat UI.

## Run locally

From the repo root:

```bash
cd "chatbot/vawa-insights/frontend"
npm install
npm run dev
```

Open the app at:
- `http://127.0.0.1:5173`

## Configure backend URL (optional)

By default the UI calls `http://127.0.0.1:8000`.

To change it, create `chatbot/vawa-insights/frontend/.env`:

```bash
VITE_API_BASE=http://127.0.0.1:8000
```
